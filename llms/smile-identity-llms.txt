## Developer Resources

- [Security](https://docs.usesmileid.com/developer-resources/overview/readme.md)
- [Changelog](https://docs.usesmileid.com/developer-resources/overview/changelog.md)
- [Mobile](https://docs.usesmileid.com/developer-resources/sdks/mobile.md): Embed Smile ID identity verification flows into native and cross-platform mobile apps with the v12 SDKs for Android, iOS, Flutter, and React Native.
- [Setup](https://docs.usesmileid.com/developer-resources/sdks/mobile/setup.md): Install the Smile ID v12 mobile SDK, register on-device ML providers, and wire up authentication.
- [Performing a Verification](https://docs.usesmileid.com/developer-resources/sdks/mobile/performing-a-verification.md): Compose a verification flow with the Smile ID v12 SDK by declaring the screens, capture types, and consent your product requires.
- [Getting Result of a Verification](https://docs.usesmileid.com/developer-resources/sdks/mobile/getting-result-of-a-verification.md): Handle the in-flow onResult callback and the asynchronous callbackUrl webhook to consume Smile ID verification results.
- [Theming and Customization](https://docs.usesmileid.com/developer-resources/sdks/mobile/theming-and-customization.md): Brand the verification flow with your own colors, fonts, and shapes, and localize every string the SDK renders.
- [Web](https://docs.usesmileid.com/developer-resources/sdks/web.md): Embed Smile ID identity verification into your web applications with the v12 Web SDKs for the V3 API — a hosted flow or composable web components.
- [Web Components](https://docs.usesmileid.com/developer-resources/sdks/web/web-components.md): Build your own Biometric KYC flow with the Smile ID v12 web components — framework-agnostic custom elements for consent, user details, and selfie capture.
- [Setup](https://docs.usesmileid.com/developer-resources/sdks/web/web-components/setup.md): Install the Smile ID v12 web components via npm or the CDN bundle, mount the Biometric KYC elements, and listen to their events.
- [Submitting Payloads](https://docs.usesmileid.com/developer-resources/sdks/web/web-components/submitting-payloads.md): Assemble the full job payload — consent, user details, identity fields, and captured images — from the Smile ID web components into a multipart POST /v3/biometric\_kyc request.
- [Theming and Customization](https://docs.usesmileid.com/developer-resources/sdks/web/web-components/theming-and-customization.md): Theme the Smile ID v12 web components with attributes, localize their strings with the localisation module, and handle right-to-left languages.
- [Web SDK](https://docs.usesmileid.com/developer-resources/sdks/web/web-sdk.md): Add Smile ID Biometric KYC to your website with the hosted v12 Web SDK — a single script tag that runs the full verification flow and submits to the V3 API.
- [Setup](https://docs.usesmileid.com/developer-resources/sdks/web/web-sdk/setup.md): Load the Smile ID v12 Web SDK script, mint a v3 token on your backend, and initialize the hosted verification flow.
- [Performing a Verification](https://docs.usesmileid.com/developer-resources/sdks/web/web-sdk/performing-a-verification.md): Run a Biometric KYC verification with the Smile ID v12 Web SDK — screen order, every configuration option, and how pre-supplied data skips screens.
- [Getting Result of a Verification](https://docs.usesmileid.com/developer-resources/sdks/web/web-sdk/getting-result-of-a-verification.md): Handle the Smile ID v12 Web SDK browser callbacks and consume the authoritative verification verdict from your callback\_url webhook.
- [Theming and Customization](https://docs.usesmileid.com/developer-resources/sdks/web/web-sdk/theming-and-customization.md): Brand the Smile ID v12 hosted web flow with your color and logo, control attribution, switch capture modes, and localize every string.
- [Server-Side (Coming Soon)](https://docs.usesmileid.com/developer-resources/sdks/server-side.md): Call the Smile ID V3 API from your backend with the upcoming server-side SDKs.
